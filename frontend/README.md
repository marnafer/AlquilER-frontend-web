# Frontend React

Aplicacion desacoplada del proyecto de alquiler. Usa React y Vite y consume la API configurada por el entorno de despliegue.

## Desarrollo

```bash
npm install
npm run dev
```

## Produccion

```bash
npm run build
```

El resultado compilado se genera en `dist/`. La configuracion de URLs de API debe incorporarse mediante variables `VITE_*` cuando se conecten los servicios reales.
